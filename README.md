# DairyFarm Report 1.9.1

Локальный сборщик отчётов DairyFarm с поддержкой нескольких баз.

Данные основных отчётов извлекаются из перехваченных ответов GraphQL DairyFarm. Чтение HTML-таблиц используется только как резервный механизм.

## Запуск

1. Распакуйте ZIP целиком в обычную папку с правом записи.
2. Дважды щёлкните `START_DAIRYFARM_REPORT.cmd`.
3. В открывшемся интерфейсе нажмите «Открыть вход DairyFarm» и авторизуйтесь.
4. Выберите общий диапазон дат.
5. Отметьте базы, которые нужно выгрузить.
6. Нажмите «Сформировать выбранные Excel».

Node.js и библиотеки уже находятся внутри переносимой сборки. Устанавливать Node.js, Codex или Playwright отдельно не требуется. На компьютере должен быть установлен Microsoft Edge либо Google Chrome.

Если окно входа DairyFarm было закрыто вручную, приложение автоматически создаст новое окно при следующем подключении или запуске выгрузки.

Для каждой базы создаются отдельные Excel и лог. Название базы используется в имени файла и записывается в служебную ячейку `Z2`.

## Подключение Google

1. Создайте OAuth-клиент Google типа `Desktop app` и скачайте его JSON.
2. В интерфейсе нажмите «Импорт OAuth JSON» и выберите скачанный файл.
3. Нажмите «Подключить Google» и подтвердите доступ в системном браузере.
4. Нажмите «Проверить шаблон».

Кнопка «Сформировать Google-презентации» собирает данные выбранных баз, создаёт отдельную копию исходного шаблона и заполняет всю презентацию: обложку, KPI, таблицы, графики и списки животных. После `ARKA` на обложке добавляется название хозяйства; исходные шрифты, цвета и оформление шаблона сохраняются. Если список не помещается, приложение автоматически добавляет слайд-продолжение. Исходная презентация не изменяется.

Кнопки Google и импорт/экспорт конфигурации находятся в сворачиваемом разделе «Настройки» внизу страницы. При запуске этот раздел закрыт.

Для исправления презентации без повторного сбора DairyFarm у каждой базы есть отдельный рабочий цикл:

1. «Выгрузить Excel» — собрать свежие данные только этой базы и скачать файл.
2. Исправить значения в двух служебных листах Excel, не меняя их названия и служебные даты в `Z3:Z4`.
3. «Загрузить правки» — проверить и сохранить исправленный Excel локально для выбранной базы.
4. «Создать презентацию» — сформировать новую Google-презентацию непосредственно из загруженного Excel.

Если исправленный Excel не загружен, презентацию можно создать из последнего собранного файла. Приложение выбирает более новый из собранного и загруженного файлов. Кнопка «Скачать Excel» позволяет повторно получить используемую сейчас версию.

Диаграммы создаются в стиле «Отчёт редизайн»: тёмно-синие столбцы, жёлтые/коралловые линии, зелёный ряд сохранности, подписи значений, круглые маркеры и легенда над областью построения. Пропорции каждого графика автоматически подстраиваются под его рамку на слайде; графики первого и второго осеменения остаются точечными.

На слайдах 3–4 значения столбчатых рядов скрыты, чтобы графики не были перегружены; график «Надой» сохраняет подписи. Подписи верхних линейных рядов размещаются внутри области построения и не обрезаются её границей.

Круговая диаграмма «Проверка УЗИ» подписывает каждый сектор процентом и добавляет в заголовок дату начала диапазона, введённого пользователем.

В таблицах сохранности месячные значения ниже 90% подсвечиваются жёлтым, а ниже 80% — красным. Значения от 90% и итоговые строки сохраняют обычную светло-синюю заливку.

OAuth JSON и полученный token хранятся только локально в `.local/google`. Они не входят в экспорт конфигурации баз и не добавляются в переносимый ZIP. На другом компьютере OAuth JSON нужно импортировать, а вход выполнить заново.

## Управление базами

- «Добавить базу» — ввод ID, названия и ссылок на все источники;
- «Изменить» — изменение названия или ссылок существующей базы;
- чекбоксы — выбор баз текущей выгрузки;
- «Экспорт конфигурации» — сохранение списка баз и ссылок в `dairyfarm-bases.json`;
- «Импорт конфигурации» — загрузка списка на другом компьютере. Перед импортом создаётся резервная копия прежнего файла.

Рабочая конфигурация хранится в `config/bases.json`.

## Остановка

Кнопка «Остановить выгрузку» закрывает активную вкладку сбора, не запускает следующие базы и сохраняет уже собранные данные текущей базы в частичный Excel и лог.

## Локальные данные

Сессия DairyFarm хранится в `.browser-profile`. Пароль приложение отдельно не сохраняет. Результаты создаются в `outputs/<ID-запуска>/`.

## Перенос на другой компьютер

Перенесите всю распакованную папку. Список баз и ссылок находится в `config/bases.json`; его также можно перенести через кнопки экспорта и импорта конфигурации в интерфейсе. Папку `.browser-profile` переносить не рекомендуется: на новом компьютере выполните вход в DairyFarm заново.
